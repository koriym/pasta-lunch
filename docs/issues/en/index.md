# Issue Types

## Coupling

- [CouplingBetweenObjects (CBO)](coupling-between-objects) - Too many dependencies in a class

## Complexity

- [CyclomaticComplexity (CC)](cyclomatic-complexity) - Too many branches in a method
- [NPathComplexity](npath-complexity) - Too many execution paths
- [ExcessiveClassComplexity (ECC)](excessive-class-complexity) - Overall class is too complex

- [DevelopmentCodeFragment](development-code-fragment) - Debug code left in production
